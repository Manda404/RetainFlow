# Strategie Retention - Client Haute Valeur

## Objectif

Proteger les clients les plus rentables ou les plus strategiques lorsque le modele detecte un risque de churn eleve, en combinant priorisation economique, diagnostic relationnel et action conseiller personnalisee.

## Segment Cible

Clients avec valeur annuelle elevee, plusieurs contrats actifs, anciennete significative, potentiel de cross-sell ou poids important dans la valeur sauvegardee attendue.

## Signaux A Surveiller

- `customer_value_score` ou `annual_premium_amount` eleve ;
- `expected_saved_value` elevee dans la file de retention ;
- multi-equipement auto, habitation, sante, prevoyance ou protection juridique ;
- churn probability moyenne ou elevee ;
- baisse recente d'engagement ;
- devis concurrent ou objection prix ;
- reclamation ouverte, sinistre sensible ou renouvellement proche.

## Diagnostic Metier

Le conseiller doit eviter une approche standard. Le diagnostic doit qualifier :

- la raison dominante du risque : prix, service, sinistre, digital, renouvellement ;
- la valeur relationnelle du client : anciennete, multi-contrats, relation agence ;
- la marge de manoeuvre commerciale ;
- le bon niveau d'escalade : conseiller, responsable agence, cellule retention.

## Action Recommandee

Declencher une action de retention premium :

- contact par conseiller senior ou responsable agence ;
- revue globale du portefeuille client ;
- priorisation de l'irritant principal ;
- proposition personnalisee : optimisation garanties, avantage fidelite, rendez-vous annuel, accompagnement sinistre ou geste relationnel ;
- suivi explicite apres contact.

## Canal Conseille

Telephone ou rendez-vous agence. Email uniquement pour confirmer le recapitulatif, les documents ou la proposition apres discussion.

## Message Conseiller

Bonjour,

Je vous propose un point personnalise sur l'ensemble de vos contrats afin de verifier que vos garanties restent coherentes avec votre situation actuelle. L'objectif est de vous apporter une reponse claire, d'identifier les ajustements utiles et de vous accompagner sur les sujets prioritaires.

## Garde-Fous

- ne pas offrir une remise sans analyse de rentabilite ;
- ne pas traiter un client haute valeur avec un message generique ;
- verifier les contraintes produit et commerciales ;
- documenter la decision et le cout de l'action ;
- escalader si le risque est critique et la valeur sauvegardee importante.

## KPI De Suivi

- valeur sauvegardee attendue et realisee ;
- taux de retention des clients haute valeur ;
- cout moyen des gestes commerciaux ;
- taux d'acceptation des rendez-vous ;
- nombre de contrats preserves ;
- evolution de la satisfaction apres action.
