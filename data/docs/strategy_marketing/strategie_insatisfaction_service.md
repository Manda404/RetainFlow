# Strategie Retention - Insatisfaction Service

## Objectif

Retenir les clients dont le risque de churn est lie a une experience de service degradee : reclamation, delai trop long, dossier non resolu, manque de suivi ou insatisfaction explicite.

## Segment Cible

Clients avec reclamations recentes, cas service non resolus, delais de traitement longs, satisfaction faible, interaction negative ou escalade vers un responsable.

## Signaux A Surveiller

- `complaints_6m` eleve;
- `unresolved_case_count_12m` superieur a 0;
- `avg_satisfaction_score_12m` faible;
- interactions nombreuses avec le service client;
- risque de churn eleve apres incident service.
- SLA depasse sur un sinistre, une demande de document ou une modification de contrat;
- dernier contact marque comme negatif, irritant ou non resolu.

## Diagnostic Metier

La priorite n'est pas de vendre. Le conseiller doit d'abord comprendre l'irritant principal :

- promesse non tenue ;
- absence de retour ;
- incomprehension de la decision assureur ;
- delai trop long ;
- sentiment de manque de consideration.

Une offre commerciale n'est pertinente qu'apres resolution ou plan de resolution clair.

## Action Recommandee

Declencher un appel de resolution prioritaire :

- reconnaitre le probleme sans minimiser ;
- reformuler les faits et le besoin client ;
- annoncer une action corrective datee ;
- affecter un responsable de suivi ;
- confirmer par ecrit ce qui a ete decide.

## Canal Conseille

Telephone avec conseiller senior ou responsable service. Si le client est rattache a une agence, creer une tache agence avec priorite haute.

## Message Metier

Bonjour,

Je vous contacte au sujet de votre derniere demande. Nous avons bien identifie qu'un point de votre dossier necessite un suivi prioritaire. Je souhaite reprendre les elements avec vous, confirmer ce qui reste a traiter et vous donner une date claire pour la prochaine etape.

Notre objectif est de resoudre le sujet avant de vous proposer toute autre demarche commerciale.

## Action Corrective

- relance interne du dossier ;
- engagement de rappel a une date precise ;
- transmission d'un recapitulatif ecrit ;
- geste relationnel uniquement si le probleme est confirme et documente ;
- escalade responsable si le dossier est bloque depuis plus de 7 jours ouvrables.

## Garde-Fous

- ne pas minimiser la reclamation;
- ne pas proposer une offre commerciale avant resolution du probleme;
- documenter l'engagement pris;
- escalader si le dossier est bloque.
- ne pas fermer une action retention tant que le client n'a pas recu la confirmation promise.

## KPI De Suivi

- delai moyen de resolution;
- satisfaction post-contact;
- retention a 90 jours;
- taux de reouverture de dossier.
- taux de respect des engagements de rappel;
- nombre d'escalades service par agence.
