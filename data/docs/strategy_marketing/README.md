# Strategies Marketing Retention

Ce dossier contient le premier corpus documentaire utilise par le `StrategyRAGAgent`.

Chaque fiche de strategie est volontairement redigee comme une note metier:

- segment client cible;
- signaux de churn;
- action recommandee;
- canal conseille;
- limites et garde-fous;
- KPI de suivi.

Le RAG se sert de ces documents pour enrichir les recommandations produites par le modele churn.
